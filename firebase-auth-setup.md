# Configuration de l'authentification anonyme Firebase

1. Accédez à la [console Firebase](https://console.firebase.google.com/)
2. Sélectionnez votre projet `ailandclean-api`
3. Dans le menu de gauche, cliquez sur **Authentication**
4. Sélectionnez l'onglet **Sign-in method**
5. Recherchez la méthode **Anonymous** dans la liste des fournisseurs
6. Cliquez sur le bouton d'activation (toggle) pour l'activer
7. Cliquez sur **Save** pour enregistrer les modifications
